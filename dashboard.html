OAuth setup

Salesforce blocks login with apps that are not installed in your org. If Generate Token fails, use one of these fixes.

Fix 1: Ask your admin

Ask your Salesforce admin to install the app: Setup > Connected Apps OAuth Usage > find the app > Install, then set who can use it.

Fix 2: Use your own app

Create an External Client App in your org and paste its consumer key below. The app needs:

  • Callback URL: Loading...
  • OAuth scopes api and refresh_token
  • PKCE turned on, and no client secret required for the web server flow or for refresh
